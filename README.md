# Java Projects

A collection of Java projects developed to strengthen programming fundamentals, object-oriented programming, problem-solving skills, and practical software development experience.

This repository contains small, structured Java applications built while learning and applying core Java concepts. Each project focuses on implementing concepts through practical coding rather than only theoretical study.

## Objectives

* Strengthen Java programming fundamentals.
* Apply Object-Oriented Programming concepts.
* Improve problem-solving and logical thinking.
* Build practical console-based applications.
* Maintain a structured record of Java learning projects.

## Technologies Used

* Java
* Object-Oriented Programming
* Java Collections Framework
* Exception Handling
* File Handling
* Git and GitHub
