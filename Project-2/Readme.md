
# Inventory & Order Management Engine

A Java-based in-memory inventory and order management system demonstrating
object-oriented programming, Java Collections, Comparators, Streams,
custom exceptions, and service-layer design.

## Features

- Product and customer management
- Product lookup using HashMap-compatible Map storage
- Stock reservation and release
- Order placement and cancellation
- Automatic order ID generation
- Product sorting by name and price
- Product filtering by minimum stock
- Product search by name
- Custom exceptions for stock and order validation
- In-memory data storage

## Technologies

- VS Code
- Java Collections Framework
- Streams and Lambda Expressions
- Comparator and Comparable
- Object-Oriented Programming


## Storage

Data is stored in memory and is lost when the application terminates.
No database or external dependencies are required.
